# 1С:Профессионал — тренажёр вопросов

Офлайн-тренажёр для подготовки к сертификационному тестированию **«1С:Профессионал» по платформе «1С:Предприятие 8.3»**: 958 вопросов по 14 темам, повторение с учётом ошибок и режим экзамена в формате настоящего теста.

**Открыть:** https://wgerads.github.io/1c-exam-trainer/

Работает в браузере на компьютере и телефоне. Его можно установить на домашний экран как приложение (PWA): после первого открытия он работает без интернета.

## Возможности

- **Повторение по темам.** Для каждой из 14 тем есть три режима: «Повторять» (все вопросы темы вперемешку), «Новые» (ещё не решённые) и «Ошибки» (вопросы, на которые последний раз ответили неверно). Каждый вопрос показывается один раз за круг, ошибки не возвращаются в очередь. В итогах круга перечислены ошибки с правильными ответами, а кнопка «Перерешать ошибки» запускает новый круг только из них. Так можно повторять, пока ошибок не останется.
- **Подсказки и объяснения.** В тренировке до ответа можно открыть подсказку (кнопка или <kbd>H</kbd>), после ответа показывается объяснение. Объяснения видны и в просмотре темы, и в разборе экзамена. Пока готова тема «Общие механизмы». Текст собственный, лежит в `data/explanations.js`.
- **Разбор темы.** Кнопка «Разбор» на карточке темы открывает теорию: схему связей объектов, таблицы, ловушки экзамена и шпаргалку. Разборы есть для всех 14 тем. Текст собственный, по файлу на тему: `data/guides/set-N.js`.
- **Картинки.** У 75 вопросов есть иллюстрация: окно конфигуратора, форма, схема или фрагмент кода. Нажмите на картинку, чтобы открыть её во весь экран; повторное нажатие увеличивает её до исходного размера файла с прокруткой.
- **Светлая и тёмная тема** включаются по настройке системы.
- **Избранное.** Звёздочка ☆ на карточке вопроса (в тренировке, просмотре и разборе экзамена, в тренировке ещё клавиша <kbd>F</kbd>) добавляет вопрос в избранное. На главной есть карточка «Избранное»: в ней можно повторять отмеченные вопросы из всех тем вперемешку, просматривать их списком и повторять ошибки. Избранное хранится в браузере и попадает в файл при сохранении прогресса.
- **Просмотр вопросов.** Кнопка «Просмотр» на карточке темы открывает все её вопросы списком с выделенным правильным ответом. Можно искать по тексту вопросов и вариантов и оставить на экране только правильные ответы. Просмотр не влияет на прогресс.
- **Режим экзамена.** Билет из 14 вопросов, по одному случайному из каждой темы. На него даётся 30 минут, для зачёта нужно 12 верных ответов. Правильные ответы показываются только в конце. Подробности ниже.
- **Прогресс.** Для каждого вопроса хранится статус: изучен, с ошибкой или не начат. Прогресс сохраняется в браузере, его можно выгрузить в файл и загрузить обратно, например чтобы перенести на другое устройство.
- **Клавиатура.** <kbd>1</kbd>…<kbd>9</kbd> выбирают вариант ответа, <kbd>Enter</kbd> переходит дальше, <kbd>H</kbd> показывает подсказку, <kbd>F</kbd> добавляет в избранное, <kbd>Esc</kbd> выходит.

## Режим экзамена

Повторяет формат тестирования, описанный на [странице учебного центра 1С](https://uc1.1c.ru/ekzameny-1s/prof/): 14 вопросов, 30 минут, для зачёта нужно 12 верных ответов.

| Правило | Как в тренажёре |
| --- | --- |
| Состав билета | По одному случайному вопросу из каждой из 14 тем |
| Время | 30 минут. Таймер краснеет за 5 минут до конца, а когда время выходит, экзамен завершается сам |
| Зачёт | 12 верных из 14 и больше. Вопрос без ответа считается неверным |
| Навигация | Между вопросами можно переходить кнопками с номерами или стрелками <kbd>←</kbd> <kbd>→</kbd>, ответ можно менять до завершения |
| Ответы | Во время экзамена не показываются. После завершения открывается разбор: верный вариант выделен зелёным, ваш неверный — красным |
| Перезагрузка страницы | Экзамен не теряется: на главной появится «Продолжить экзамен», а таймер идёт по реальному времени |

Результаты экзамена записываются в общий прогресс, поэтому ошибки из билета появятся в режиме «Ошибки» своей темы. Последние 20 попыток сохраняются, а пять последних видны на главной.

Вопросы с картинками участвуют в экзамене наравне с остальными. Если в будущем появится вопрос со ссылкой на рисунок («на рисунке», «на картинке»), а картинки к нему не будет, в билет он не попадёт.

## Как запустить локально

Сборка не нужна: это статические файлы.

```bash
git clone https://github.com/wgerads/1c-exam-trainer.git
cd 1c-exam-trainer
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно просто открыть `index.html` двойным щелчком. Всё будет работать, кроме офлайн-кэша: service worker регистрируется только на `https://` и `localhost`. В некоторых браузерах при открытии из файла может не сохраняться прогресс, тогда приложение об этом предупредит.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Страница приложения |
| `app.js` | Интерфейс: экраны, события, сохранение в `localStorage` |
| `app-core.js` | Чистая логика без DOM: очередь вопросов, проверка ответа, прогресс, сборка и оценка экзаменационного билета |
| `app.css` | Оформление, адаптивное под телефон |
| `data/questions.js` | Банк вопросов (`window.EXAM_DATA`) |
| `data/explanations.js`, `data/guides/` | Подсказки и объяснения к вопросам, разборы тем |
| `images/questions/` | Картинки к вопросам (`<id вопроса>.webp`), вырезаны со скриншотов тренажёра и увеличены в 3 раза (в `data/questions.js` поля `w`/`h` — размер исходного кадра) |
| `sw.js` | Service worker для офлайн-работы. При изменении файлов нужно поменять `VERSION`, иначе установленное приложение останется на старой версии |
| `manifest.json`, `icons/` | Установка как приложения |
| `tools/test-app-core.mjs` | Тесты логики |

## Тесты

Нужен Node.js 18 или новее.

```bash
node --test tools/
```

Тесты проверяют проверку ответов, очереди повторения, избранное, сборку билета (по одному вопросу из темы, без вопросов с картинками), порог зачёта 12 из 14, формат таймера. Ещё они проверяют, что у каждого вопроса банка есть правильный ответ.

Формат одного вопроса в `data/questions.js`:

```json
{
  "id": "set-1-q001",
  "categoryId": "set-1",
  "categoryTitle": "Общие механизмы",
  "text": "В какое значение можно установить свойство \"Серии кодов\" объекта конфигурации \"Справочник\"?",
  "options": [
    { "id": "a", "text": "Во всем справочнике", "correct": false },
    { "id": "e", "text": "Верны все указанные ответы", "correct": true }
  ],
  "multi": false,
  "needsReview": false,
  "image": { "src": "images/questions/set-8-q004.webp", "w": 318, "h": 263 }
}
```

Поле `image` есть только у вопросов с иллюстрацией. У вопроса есть и служебные поля распознавания: `confidence`, `verified`, `layoutNote`, `sourceImages`. Приложение их не использует.

### Сверка со скриншотами

Банк сверен с исходными скриншотами официального тренажёра (972 кадра, июнь 2026 года). Все вопросы банка на скриншотах есть, правильные ответы совпадают с зелёной подсветкой. Число вопросов в каждой теме совпадает с тренажёром, кроме «Интерфейсных механизмов».

### Известные ограничения

- **В «Интерфейсных механизмах» нет трёх вопросов из 128**: № 44, 104 и 114. Их нет ни на одном скриншоте, а у № 44 есть только кадр с вариантами, текст вопроса прокручен за край экрана.
- **Картинки мелкие в источнике**: в тренажёре 1С они показываются уменьшенными (около 320 px в ширину). Файлы увеличены в 3 раза с подавлением шума JPEG, повышением контраста и резкости (sharp: `blur 0.4` → `resize ×3 mitchell` → `normalise` → `gamma` → `sharpen`), поэтому читаются лучше. Но детали, которых нет на скриншоте, так не восстановить: самый мелкий текст на части картинок всё равно разбирается с трудом.
- **32 вопроса помечены «для проверки»** (`needsReview`). Чаще всего на скриншоте был обрезан верх текста вопроса или нижний вариант ответа. Ответ у них определён, но формулировка может быть неполной.
- **`set-13-q011`** (символы маски кода): кавычки и символы в первом и третьем вариантах распознаны неточно.
- Банк собирался скриптом `tools/build-bank.mjs` со скриншотов, но этого скрипта в репозитории нет. Поэтому `data/questions.js` сейчас правится вручную.

Официальный банк вопросов периодически обновляется. Сверять его стоит с бесплатным учебным тестированием на [uc1.1c.ru](https://uc1.1c.ru/ekzameny-1s/prof/) (нужна регистрация) или со сборником «Комплект вопросов сертификационного экзамена „1С:Профессионал“ по платформе».
